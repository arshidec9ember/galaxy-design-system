Typography

Typography is a key element of a design system which helps to establish hierarchy, readability and visual appeal. It defines the text styles that are used across all the scenarios. It includes the font(s) to be used along with the type scale and the style variations. This helps in establishing consistency and all the benefits that follow consistency.

Typeface

GDS uses the open-source typeface IBM Plex. IBM Plex illustrates the unique relationship between mankind and machines. It is a neutral, yet friendly Grotesque style typeface that includes a Sans, Sans Condensed, Mono, Serif, and several other styles for several languages. It has excellent legibility in print, web and mobile interfaces.

GDS currently uses the Sans and Mono styles. The Sans style is versatile and is used for headings, body, labels and numbers while the Mono style is used for code snippets, currency amount and ID strings.

Scale

A typographic scale helps maintain consistency in font sizes and creates a harmonious layout.

GDS typographic scale is built on a single equation. The formula was created to provide hierarchy for all types of experiences.

Xn = Xn-1 + {INT[(n-2)/4] + 1} * 2

Xn: step n type size Xn-1: step n-1 type size

Line Height

Line height, also known as line spacing or leading, refers to the vertical space between lines of text in a paragraph. It is measured from the baseline of one line of text to the baseline of the next line.

Line height plays a crucial role in readability and legibility. In GDS, the recommended line height is 1.5x font size.

Letter Spacing

Spacing between the letters determines the density of the font. All fonts have a default spacing of 0px. But it can be adjusted based on the specific requirements. For example, the spacing could be increased for smaller font sizes to improve the readability. It could also be reduced for large font sizes to close the additional gap that results from scaling the font.

Properties

Formatting Styles

- Font Weights

Font weight is an important typographic variable that is used to add emphasis and differentiate content hierarchy. Font weight and size pairings must be carefully balanced. A bold weight will always have more emphasis than a lighter weight font of the same size. However, a lighter-weight font can rank hierarchically higher than a bold font if the lighter-weight type size is significantly larger than the bold one.

- Italics

Each weight has an italic style, which should only be used when you need to emphasize certain words in a sentence. They can also be used for names, captions, technical terms etc.

- Decoration

Underline

Text that is underlined can serve two purposes: linking to other pages, or offering additional contextual information through a tooltip or a popover.

Strike Through

Strikethrough is a text decoration style that draws a horizontal line through the middle of the text. It is commonly used to indicate that the text is no longer relevant or has been deleted.

Case

Cases determine the appearance of letters and words in a sentence. It could be:

  • Upper case: All letters are capitalized. Example: "HELLO, WORLD!"

  • Lower case: All letters are in lowercase. Example: "hello, world!"

  • Title case: The first letter of each word is capitalized, except for articles, conjunctions, and prepositions. Example "The Quick Brown Fox Jumps Over the Lazy Dog"

  • None (as typed): Keep it as it is how the user types. Example: "The quick brown fox jumps over the lazy dog."

Refer the content guidelines to understand the usage of each case.

Type Colors

Type color should be carefully considered, with legibility and accessibility as paramount concerns.

GDS has several pre-built color tokens that should be used for most text colors. If any other colors need to be used, the color choice should consider accessibility and legibility. Refer the Color foundation document for additional guidance.

Token Composition

Fonts are always used along with their styling values. Therefore, in GDS the font tokens are created as composite tokens by composing all the required styling variables.

For example, from the above font tokens, each token represents a font along with all its styling values. i.e, body-large is composed of the font family, font size, weight, line height and letter spacing.

Usage Guidelines

Do’s

Make sure to use the pre defined fonts (as listed above) across all use cases and themes.

Keep the line length ideal i.e 50-75 characters (including spaces) to make the content easily readable.

Follow appropriate heading levels to maintain hierarchy.

For code snippets use the monospaced font version, which is the token “code” (composed with IBM Plex Mono)

Don’ts

Don’t underline for adding emphasis to any text.

Avoid using all caps for body text. Refer the content guidelines and respect the capitalization rules.
