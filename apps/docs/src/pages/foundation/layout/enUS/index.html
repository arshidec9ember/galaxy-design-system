Elements & Configuration

The GDS layout is generated by utilizing slots, which are CSS containers integrated with a flexbox. These slots serve as the principal area where multiple components are placed and are usually composed of vital elements like the Header, Aside, Main container, and Footer. These elements are integral to the layout and can be structured accordingly based on the requirements of the product or application screen. The combination of these elements may be mandatory or optional depending on the specific design needs.

Elements

Header slot: The Header slot is allocated the highest position in the visual hierarchy and is typically positioned at the top, accommodating components such as the Global header, Wizard header, and other similar elements.

Aside slot: The Aside slot is the second-highest priority container in the layout that is typically located on the sides of the screen. The placement of the component depends on the product's screen narrative, with the most common positioning being on the left side. However, it can also be placed on the right side, and in certain cases, two aside components can be utilized together. These can be aligned together on one side, placed consecutively, or positioned separately on either side.

Main container: The Main container plays a critical role in hosting a range of component slots that can be organized vertically or horizontally as per the product screen's specifications. Positioned at the third-highest point in the visual hierarchy, it is typically situated adjacent to the Aside slot or nestled between two Aside slots.

The Main container is constructed with precise specifications, maintaining a uniform padding of 24 px on all four sides to ensure a consistent layout throughout the product.

Footer slot: The Footer slot is an integral component of the layout composition, ranking fourth in the visual hierarchy. It is commonly utilized to exhibit decision/action elements or navigation features like pagination, based on the screen requirements.

In some scenarios, the Footer slot is integrated with the Main container, whereas in other use cases, it can assume a global identity, as seen in the Wizard layout. The Footer slot's strategic positioning and versatile utility make it a crucial aspect of the overall layout design.

Configuration

The layout structure can be modified using the aforementioned elements to cater to diverse screen specifications. The following layout templates provide a comprehensive overview of the possible design configurations, allowing for maximum flexibility and customization.

Header slot + Aside slot + Main container slot

This particular layout combination represents the default structure of GDS, utilizing three essential components: the Global header occupying the header slot, the primary sidebar located in the aside slot, and the main container showcasing pertinent content, including form fields, tables, cards, and other related items.

Header slot + Aside slot + Main container slot + Footer slot

The aforementioned layout structure is commonly employed in a wizard layout, which employs all four elements. Specifically, the wizard header is situated in the header slot, the stepper occupies the aside slot, the main container displays form fields or other pertinent content, and the footer slot contains the action items.

Header slot + Main container slot + Footer slot

This layout structure presents unpartitioned data in a single layout, where the side navigation slot is excluded and the global header occupies the header slot. The main container itself is segmented into various slots that can display different elements such as form fields, cards, graphs, view-only content, or other relevant content in their respective slots.

Header slot + Aside slot(left) + Aside slot (left) + Main container slot + Footer slot

This layout follows a structure akin to the aforementioned initial combination but includes two aside slots to accommodate both a primary sidebar and a secondary sidebar for navigation and exploration purposes. The secondary sidebar can be substituted with either a stepper or a list navigation component.

Header slot + Aside slot (left) + Main container slot + Aside slot (right) + Footer slot

This layout bears resemblance to the aforementioned structure, as it also employs two aside slots, however, they are positioned on opposite sides of the main container, serving as a space for additional content, navigation, or related information.

The layout combinations described above can be customized according to the specific needs and flow of the product. As a result, numerous possible variations can be created, but the structures outlined above are commonly used in applications.

Behavior

Responsiveness

The layout structure is built with a responsive approach, utilizing flexbox to deliver optimal results. However, certain components may possess fixed height with fluid width, including global headers, page banners, and top bars. In contrast, navigation components may feature fluid height with fixed width. Certain components may exhibit both fluid width and height, depending on their unique characteristics.

For resolutions, less than 1024 px in width, the limited real estate available may result in compromised visual representation.

Collapsible Aside

In certain layouts, the aside components such as the primary sidebar and secondary sidebars can be collapsed, thereby reducing the screen width and increasing the width of the main container. This results in additional real estate on the main container, which can dynamically adjust to fit the available width. Such responsive behavior provides more efficient use of available screen space and enhances the overall user experience.

Grid

The layout employs a 12-column grid structure for grouped elements such as cards and form fields. This involves defining the number of columns allocated to each item within the group, within the main container. The grid system utilizes flexbox and is dynamically calculated by the framework, without requiring a fixed container width. The grid is applied within the specified slot of the main container, without margins, based on the width of the slot and gutter provided, with the 12 columns evenly distributed.
