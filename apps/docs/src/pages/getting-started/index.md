# Getting Started with GDS
A step-by-step blueprint to propel your energy in the right direction.

Using Galaxy Design System is easy and fast, so is getting started with it. Below you’ll find everything you’ll need to start building using Galaxy Design System —

## Who should use GDS?

Galaxy design system is created to build all of Zeta’s back-office products. It should be used by both, the design teams and the front-end development teams.

## Understanding GDS

As we know, “The whole is greater than the sum of the parts”.At the basis of GDS, we have systems thinking, design principles, development principles, best practices, and the latest approaches to building scalable and modular systems. All of these forms the hidden force that propels GDS.

GDS is consumed in the form of the GDS Library. Which consists of three high-level parts.
**Foundation**, **Components**, and the **Patterns** (coming soon). Get started by familiarizing yourself with the contents of this library.
