# Galaxy Design Components

Galaxy Design Components is a Vue 3 component library.

To know how to install it, see [Installation](installation).

It is modular, themeable, written in typescript and is fast.

## Fairly Complete

There are more than 65 components which can help you write less code.

What's more, they are all treeshakable.

## Theme Customizable

We provide an advanced type safe theme system that is built with typescript. All you need is to provide a theme overrides object in JS. Then all the handling will be done by us.

What's more, no less/sass/css variables, no webpack loaders are required. And you can try the theme editor on the bottom right of the page.

## Uses TypeScript

Everything in Galaxy Design Components is written in TypeScript. It can work with your typescript project seamlessly.

What's more, you don't need to import any CSS to use the components.

## Fast

This library is fast, scalable and easy to you. Few components like select, tree, transfer, table and cascader have an inbuilt support of virtual list.

What's more, ..., no more. Start consuming it.
