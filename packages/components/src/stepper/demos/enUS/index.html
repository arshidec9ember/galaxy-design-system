Anatomy

Stepper consists of multiple puzzle pieces put together:

Stepper: The main component that comprises of the end state of what would be used

Stepper Item Group: Consists of the actual stepper items joined and put together. There are few default steps already provided to save time. EX: Vertical stepper item group comes by default with 3, 4, 5, 6 stepper groups pre-defined

Stepper Item: Consists of the various elements that makes a stepper item (Step counter, Progress Line, Label)

Elements

Stepper Item Group

Indicates a step in a sequence, highlights the current step, displays the completed and incomplete steps. It also lets users navigate between different steps. By default you can take advantage of the pre-defined step groups (3-6)

This component comes in two variations based on the orientation : Horizontal & Vertical

On top level we have two states for the component: Expanded & Collapsed.

  • Only Vertical Stepper comes with this interaction states.

On Step level we have interactive states like :

  • Incomplete: A step indicator by default is in an incomplete state unless the user completes it.

  • Hovered: This state defines the visual feedback of a step when hovered over.

  • Focused: The focused state communicates the feedback when a user has highlighted a step using a keyboard or voice.

  • Selected: Selected step signifies the step a user is currently interacting with.

  • Completed: When a user completes a step the step transitions to a complete state.

  • Disabled: This state disables the step based on context and use-case.

  • Error: This state indicates if any error occurred in the specific step.

Variations

Stepper component only have two variations based on the orientation and which orientation to use depends on the availability of the real space.

Horizontal stepper

Consists of horizontal variation of stepper component and to be used for smaller forms and processes. Mostly used in modals and side-sheets.

Vertical stepper

Consists of vertical variation of stepper component and to be used for larger forms mostly in wizards and full-page.

Behaviours

Navigate using stepper item:

By default, the interaction of the stepper panel blocks the user to jump between the steps unless the previous steps are complete. However, users can use stepper item to navigate to different steps. This help users to quickly jump to certain steps if they want to.

Although this behaviour comes along with configuration. For example if you are using this stepper component inside wizard with restriction that previous steps needs to be completed before going to next steps, then other than the Active and completed steps all next steps will be in disabled state.

We suggest to stay away from this interaction unless it is necessary and provides a value add to the use case you are presented.

Text Overflow:

If the content exceeds the designated space then the content will be truncated, although it is advisable to use terms that will fit and avoid longer terms.

Expand/Collapse

Just like the sidebar, stepper can also be collapsed. This gives the user the ability to hide stepper labels when it is not needed and make use of more space.

Usage Guidelines

Use badge component to show the status if any.

Avoid using right aligned row item type for normal text.

Avoid using the subheading if there is no need
