Anatomy

Timeline component as specified is of multiple types:

  1. An interactive version where users will have the ability to interact with the individual steps of the timeline and see any/or all details that is relevant to that particular timeline entity.

  2. A static version where it mostly acts as a view only component that does not come with none to minimal interactive ability. The interaction is mostly confined to any CTA button element.

Even though they have like multiple variations of it, the core skeleton of it is mostly consistent made of common elements put together.

Variations

Interactive: without Badge

For simpler states like success, danger that doesn’t require custom status badge, you can choose to use this variation of interactive timeline component. This component by default come with a standard set of status icons to depict the most common scenarios.

Interactive: with Badge

For timeline states that have convoluted states which require to showcase badges and provide such affordance, this is component type to choose.

Static

It could used for any sort of timeline component that has primarily a view only use case and do not require any sort of interactive ability with the component itself.
