Anatomy

Page Banner anatomy consists of informative elements like Heading, description and status. It also includes navigational element Breadcrumbs for quick navigation.

And also includes actionable elements like CTA’s ( primary, secondary and kebab menu ). It can also accommodate the pattern image or an illustration and theme specific BG.

Variations

Rich Variant

Rich variants are primarily used to gather users’ attention over a specific topic or action.The rich variant offers an attractive background with contrast colors for providing a better visual guidance.

Rich variant is structured as LHS & RHS,
where LHS has
1. Breadcrumb
2. Title + Badge
3. Description

RHS has Pattern BG or Action group.

Note: We should not show both pattern and BG at the same time.

Plain Variant

Can be used anywhere in place of our rich banner. Simple and subtle version of banner. Like the rich banner, plain banner is also structured in same way and same elements except the patterns image and the BG.

Onboarding

Unlike rich and plain, the onboarding banner is only used upon the onboarding of the user in a product. It will act as the empty state.
Onboarding variant is structured as LHS & RHS,
where LHS has

  1. Title

  2. Description

  3. Actions Placeholder

RHS has Illustration

Home

The Home banner is only used upon the Home page layout where it doesn’t have the sidebar and it has dark global header and this banner. This one is structured in a same way as Onboarding banner, where Title, Description & Actions on the LHS and Illustration of the RHS.

Behaviours

Height & Width

The height of the banner is based on the content and the width is depends upon the Layouts & Grids. You can also check how banners behave in different viewports here.

Breadcrumbs

Clicking on different levels in breadcrumbs will take you to the respective screens. Check more info on Breadcrumbs here

Note: The Page title shows the current page information, so we should not show the current level in breadcrumbs since that information is redundant.

Actionables

Page banner ideally provides a way for a user to address page related issues with help of primary and secondary CTA’s. You can use these CTA’s to provide page level actions or entry points for creation screens. And for this we are using Action group components.

BG color, Pattern image & Illustration

Color of the banner, Pattern image and Illustration that we are using are theme dependent. Currently we have one for Aphrodite, Olympus and Optum themes.

Usage Guidelines

Use breadcrumbs incase of multi level navigation for better accessibility

Use onboarding banner only for the onboarding as the empty state to start with.

Do not change the placement of the action CTA’s as they are included in the component.

Do not use page banner in middle of a page

Do not use Home type page banner in the normal page templates, where the page already has sidebar.
