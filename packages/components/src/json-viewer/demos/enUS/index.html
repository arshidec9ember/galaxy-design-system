Anatomy

Variations

Light & Dark

Json viewer has two theme options, which is light and dark. The usage is depends upon the placement and product where we are using it.

Elements

Header

Header acts as a initial identifier to provide extra context for the json viewer. It is an optional element and can be used when required. It also have description which is an optional element.

Code Block

The code block consists of

  1. Line numbers

  2. Json Code

The line numbers is act as an identification of total no. of lines as well as the current line where the cursor is in. It is also an optional element, enabled by default.

Data Types

The Container which holds the json code which support different data types. That can be String, Numbers, Objects, Arrays, Boolean, Null etc.

String: A string is a sequence of zero or more Unicode characters, enclosed between " and " (double quotes).

Numbers: JSON number has some numbers which include digits between 0 and 9. It can be a negative number (e.g. -10.) and decimals (e.g. 0.5).

Objects: An unordered set of name/value pairs inserted between {} (curly braces). An object can contain zero or more name/value pairs. Multiple name/value pairs are separated by a , (comma).

Arrays: An ordered collection of values. Begins with [ (left bracket) and ends with ] (right bracket). It’s values are separated by , (comma).

Boolean: Booleans values can be either true or false. Boolean values are not surrounded by quotes and will be treated as string values.

Null: When there is no value to assign to a key, it can be treated as null. null value should not be surrounded by quotes.

Expand/Collapse Section: As per the structure of json, we can expand and collapse each div section

Features

Copy Action

We can copy the entire code by using the copy action on top right corner of the code block. It is optional element and we can enable whenever required.

Show More/Less Action

At end of the code block, has a show more/less action and its also an optional element. The requirement of action on the row item is depends upon the usecase.

  • The width of the Content View is flexible. It can be shrinked or expanded as needed.

  • the Height of the Container is depends upon the content inside it, if we need to provide more data on minimal space we can also provide show more/less accordion to hide few items and view upon the click.

Usage Guidelines

Follow proper json’s data and structure guidelines.

Avoid using dark mode when there is no need. It might give more emphasis which is not needed on most scenerio.
