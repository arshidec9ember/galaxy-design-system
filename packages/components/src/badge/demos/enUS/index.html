Anatomy

Container: Badge containers contain the badge elements (Label and icon).

Icon (optional): Supports or directly communicates the metadata meaning, always left-aligned.

Text: Conveys the information of the metadata.

Variations

There are two categories of badges based on color.

  • Default Badges
    Used for general-purpose, when there’s no specific meaning associated with the color of the badges.

  • Colored badges
    Used for visual highlights and/or for associating semantic meaning or creating correlation between the information.

Behaviors

A badge is static (non-interactive) in nature.

Text overflow

Ideally, the badge label should be short, concise, and contextual, and long text should be avoided. However, when a badge's label is too long for the available horizontal space, it could truncate or wrap to the next line depending on the use case and context.

Usage Guidelines

Do’s

  • If badge groups overflow out of the container then truncation can be applied by using a badge that represents the number of truncated badges .

  • Badges should be efficiently labeled with short and scannable copy.

  • Avoid using phrases in the badges.

Don’ts

  • Avoid using an icon only badge. It may create ambiguity. Text labels are recommended to be used.

  • Avoid using badge with the primary color container as it may confuse users with an actionable button.

  • Avoid grouping badges with different anatomy to show similar type of information.
