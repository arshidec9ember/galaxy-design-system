Variations

A text input component is classified into two types based on usage.

Text Field

A text field component is used to display, input, or edit alphanumeric values.

Password

A Password field component is the same as the text field, with added functionality of masking the characters and a toggle button to hide/show the mask/characters.

States

Interactions aid users in understanding every state of the component the user interacts with, each state represents an action that is either performed or triggered in the course of form filling.

  • Default: The default state is a state zero of the component before the user interacts or performs any action over it.

  • Hovered: It defines the visual feedback of the fields when hovered over.

  • Focused: Focused is triggered when a field is activated by either clicking or navigating to it using the keyboard or voice.

  • Filled: It represents the filled state of a field with the characters.

  • Disabled: It is an inactive state in which the user can not interact with the component. A state change can be triggered by providing permission to edit or by performing a prerequisite action.

  • Read-only: It is an inactive state in which the user can see and read the information displayed in it. But cannot edit it.

  • Error: It represents the error and highlights the field to aid the user to enter the correct information. It is triggered when the field validation fails.

  • Success: It represents the success and highlights the field and provides feedback on the correct information. It is triggered when the field validation is successful.

  • Error: It represents the warning and highlights the field and provides feedback to enter the appropriate information. It is triggered when the field validation is partially correct.

  • Password - Hidden: The password-hidden state masks the characters entered by the user for security purposes.

  • Password - Revealed: The password reveal state shows the characters entered by the user to allow them to verify the password.

Behavior

Text Field

When a field is focused the placeholder text is hidden to allow the users to focus on entering the information.

Character Count

When a character count is set for input, it is displayed in the top right corner of the field. It helps the users view the number of characters allowed and the number of characters entered.

Password Field

The Password field by default contains hidden text that can be viewed by using the eye icon toggle button. Toggling it on reveals the password, toggling it off hides it again.

Usage Guidelines

Do’s

Display the labels and placeholders to provide context to the users.

Error messages should be short and helpful. Try to use user-friendly words instead of technical jargon.

Don't 

Don’t show important information as placeholder text. Use the Help icon instead.

Don’t use a read-only state for the purpose of disabling a field. Use the disabled state instead.
