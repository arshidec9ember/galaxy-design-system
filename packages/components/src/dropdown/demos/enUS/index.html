Anatomy

Options

Search

Search can be placed on top of the dropdown where we can able to search inside the pool of list items.

Behaviour

Open/Close

Opening the dropdown is caused by the clicking upon the Button, which is the trigger point. By default the closing happens when clicking on the outside. But in some scenario the closing depends upon the type of popover content. For eg, if the dropdown has nested menu (chevron), the the popover wont close if I choose the action.

Width, Height

There is no minimum width as such but maximum width is set as 392px for a dropdown. The width can be customized appropriately for its context.

Text Overflow

The text will truncate with ellipses if it reaches the max width of the popover, which is 400px.

Nested Menu

Nested menus are an extension of dropdown menus. They save screen space by organizing a long list of items into categories that the user can click to reveal deeper levels.

 

Usage Guidelines

Don't

Avoid using just an icon as a trigger point, use button instead.
