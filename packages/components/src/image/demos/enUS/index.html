Variations

The image component has three different categories which support four different sizes.

Characteristics

Sizes

Each variant of the component can scale up to four different sizes in general and default being the medium size.

  • Small: 24px

  • Medium: 32px

  • Large: 40px

  • X Large: 56px

  • Custom size

Nesting

The image component is encapsulated within different components or a space in which each of these independent components with repositories is linked with it, these repositories use the image component in which the logos are updated.

Interaction

The component can be clickable, and on-click the component might elaborate details about the represented user or an entity through different components like dropdowns, popovers, etc.

Behavior

Image fit

The image component uses different aspect ratios that suites the user’s needs, these images when uploaded in larger sizes tend would automatically fit within the provided container dimension, for example when a larger resolution image is uploaded in a smaller sized container then the component automatically fits the larger image according to the given sizing that is provided.

Usage

The image component is encased within smaller components that require users to upload images These images could be of different logos or user profile pictures, the components in which the image components are used is

Avatar

An Avatar is a visual cue used as a representation to denote an entity, the entity can be a user or an organization depending upon different scenarios in which the avatar component is used. In an avatar component, the picture variant uses a Circle image component inside which can be used to upload an image of a user.

Client logo

The Client logo holds the repository of different logos in different aspect ratios and sizes, The variant uses Square & Rectangle variants of the Generic image component encased inside and hosting these other logos uploaded from the library.

Generic image

The purpose of the generic image component is to provide flexibility over the raw attribute, if the image component allows users to choose different aspect ratios and upload custom logos that are not part of the library, the component can be used in components like cells of a table, list with images and other places where an image needs to update.

Usage guideline

Don’t

Do not stretch the image to fit the size of the component
