Anatomy

States

Interactions aid users in understanding every state of the component the user interacts with, each state represents an action that is either performed or triggered in the course of form filling.

  • Default: The default state is a state zero of the component before the user interacts or performs any action over it.

  • Hovered: It defines the visual feedback of the field when hovered over.

  • Focused: Focused is triggered when a field is activated by either clicking or navigating to it using the keyboard or voice.

  • Filled: It represents the filled state of a field with the characters.

  • Disabled: It is an inactive state in which the user cannot interact with the component. A state change can be triggered by providing permission to edit or by performing a prerequisite action.

  • Error: It represents the error and highlights the field to aid the user to enter the correct information. It is triggered when the field validation fails.

  • Expanded: The expanded state is triggered when the popover is opened.

Behavior

Feedback

  • Single Select: The selected item label is displayed as it is.

  • Multiselect: The count of the total number of the selected items are displayed.

Interaction

Clicking the field in zero state opens the popover and clicking it again in the expanded state or clicking outside the popover or selecting an item from a single select list collapses.

Usage Guidelines

Don’t

Avoid using the Select Field when the feedback for multi-select items needs to be displayed as the actual content. Use the combo box instead.
