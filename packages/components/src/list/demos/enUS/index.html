Anatomy

Types

List component has two types

  1. Simple List

  2. Rich List

Simple List

The simple list component has simple text label and other optional elements like icons, chevron, description and mostly used for popover.

Rich List

The Rich list component has More prominent icon with a bounding box along with the List label and descrption. It also has a chevron to indicate the list item is clickable and it will open the relevant page/window. It is to be noted that there is no optional element present in this Rich list.

There are two more variations of the list based on the spacing between the list options as well as the icon and option text.

Default spacing variation is majorly used in popovers while the variation with increased spacing is used where multiple lists inside a container are to be showcased on a single page and default spacing looks too cluttered.

Simple List Options

List component has list item labels, which is the default element. In addition to the Label, it has various elements which includes a

  1. Icon/Image: To represent the particular list item visually more clear.

  2. Description: To add more context to the list item

  3. Chevron: To create a multiple level hierarchy.

  4. Divider: To create segregation for grouping.

All these can be used by any combination.

Sub Heading and Dividers

Subheading may used to organize or differentiate the type of list items, And the dividers may use to group the lists and other entities. The divider is compulsory when we use Description.

And also we can use divider to segregate the two groups. It will help user to identify the relevant options/actions without using the subheading.

States

List has some default interactive states and can be change as per the context.

Behaviours

Width of the List item

The width of the list item is depends upon the container width.

Text overflow

Ideally, the label should be short, concise, and contextual, and long text should be avoided. The number of character the length of the Label is depends upon the container where the list is placed inside. However, when a label too long for the available horizontal space, it could truncate or wrap to the next line depending on the use case and context.

Loading more List items

  • Scroll with Lazy Loading (default)

  • Scroll with Load more action (rare case scenario)

Usage Guidelines

Don't

Avoid using different variations of multiple list items together. It makes it difficult for the users to understand the options and increases the cognitive load.

Avoid using long descriptions in list items. Use the list with a dedicated description line instead.
