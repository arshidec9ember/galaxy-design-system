Anatomy

Variations

Horizontal

The tab items are stacked horizontally and the container which binded with the selected tabs will come at the bottom of the tab bar. This can be used when we have very less no. of tabb items and if we need more vertical space.

Vertical

The tab items are stacked vertically and the container which binded with the selected tabs will come at the right side of the tab bar. This can be used when we have more no. of tab items and if we need more horizontal space.

Configurations

Label Only

This is the most basic and commonly used tab style. It is a plain text only style.

Label with Icon

This variation consists of an icon along with the tab label. Using an icon makes a tab richer in it’s visual language. It helps users relate and identify the tab content more easily, particularly when the similar icons are used elsewhere across the product to represent similar content.

Sizes

Tabs are currently available in two sizes. Both the sizes can be used as main navigation in any layout depends on the total available space for the component.

The difference in size can also be used to create the hierarchy of importance in a single page.

Note: This can be applicable only for the Horizontal Tabs.

Two sizes are :

  1. Large ( 40 px )

  2. Medium ( 32 px )

States

There are six states for both the types of tab to show different type of interactions:

  • Normal: 

The typical state of a tab that represents it can be interacted with and is not in a selected state.

  • Hover:

This state defines the visual feedback of a tab when hovered over.

  • Focused:

The focused state communicates the feedback when a user has highlighted an element using a keyboard or voice.

  • Pressed:

The pressed state communicates that user initiated click on a tab and according to that state will change after the release of the click.

  • Selected:

This states indicates the selection of a tab after a click, tap or press is successfully performed on an unselected tab.

  • Disabled Active :

This state is used to block all interactions on a tab, such as hover, focus and click.

Behaviours

Horizontal Tabs overflow

Whenever a situation like this happen when your container width is not enough to contain all the required tabs then your tabs become scrollable.

In this situation user can scroll horizontally using mouse/trackpad or simply use the provided arrow icons on both sides to easily navigate through tabs.

Vertical Tabs overflow

When the no. of tabs are more than the container or the container height is lesser than the vertical tabs, the entire tabs inside the container will scroll vertically.

Selection Indicator

The selection indicator below the selected tab scrolls over the separator when a tab is selected.

Keyboard focus

Users can trigger a tab selection by pressing Enter or Space while the tab is in focus.

Usage Guidelines

Don’ts

  • Do not use long phrases for tab labels.


  • Avoid using punctuation marks such as periods, exclamation, etc in the tab labels.


  • Do not use tabs for a value selection (data input). Use the Segment control instead.

  • Do not use tabs if the container is lesser space than the tabs
