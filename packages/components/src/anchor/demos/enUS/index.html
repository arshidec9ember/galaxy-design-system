Anatomy

Variations

The anchor navigation component has 2 configurations, default and nested - which can be toggled based on how the content is structured on the page where the component is being used

Default

The default configuration of this component only has Level 1 items and should be used when the content on the page doesn’t have any sub-sections.

Nested

The nested configuration of this component has both Level 1 and Level 2 items, and should be used when the content on the page has sub-sections.

Level 1 and Level 2 items

Both level 1 and level 2 items have the following states -

  • Default
    The typical state of the menu item that represents it can be interacted with and is not in a selected state

  • Hovered
    This state indicates the user that a menu item can be interacted with by providing a visual feedback when hovered over

  • Selected
    This state indicates the actively selected item in the anchor nav, it does so by providing a visual change along with a selection indicator - which additionally helps indicate where the section is located on the page

  • Pressed
    The pressed state communicates a user click, tap, or press

  • Focused
    The focused state communicates when a user has highlighted an element using a keyboard or voice

Behaviors

Placement

The anchor navigation should be placed on the top right of the screen, with 24px padding from both, top and right.

Width & Height

The anchor navigation width stays fixed at 160px, it doesn't stretch or shrink on different viewports. The height of the anchor navigation isn’t fixed and is dependent on the number of list items in it.

Text Overflow

If the content exceeds the designated space in the level 1 or level 2 items, it wraps to the next line.

Usage Guidelines

  • Don’t use the “On this page” header title more than once in the anchor navigation

  • Avoid adding custom section headings in the nested anchor navigations. The section headings should be the same as the actual sub-headings on the page for the users to jump to
