Anatomy

  1. Node icon: Signifies that there is some content inside the node.

  2. Parent node: A node that contains other items and does not sit within another node (for example, a folder that contains some content inside the node).

  3. Child node: A node within the parent node (for example, a folder within a folder).

  4. Leaf node: A node without children.

  5. Action: A node can have actions that are available on hover.

  6. RHS content: To show contextual content related to the items.

Variations

Basic Tree

It consists of a hierarchy on the left and corresponding content on the right. The hierarchy can be upto four levels, We can also add more levels since the logic of each level is the indentation of 20px.

Tree with Checkboxes

A tree can be configured with checkboxes, to allow selecting multiple items.

Tree with Actions

A tree can be configured to have action buttons on hover.

States

  • Collapsed
    A tree node by default is in collapsed state with all content hidden. Starting in this state gives the user a high-level overview of the available information.

  • Expanded
    A node in an expanded state reveals the content inside it progressively. The color of the node icon at the start of the node indicates which state the node is in.

  • Hover
    This state defines the visual feedback of a node when hovered over. Based on the configuration this state can also display actions.

  • Focused
    The focused state communicates the feedback when a user has highlighted an element using a keyboard or voice. Based on configuration this state can also have actions similar to the Hover state.

  • Disabled
    This state is used to block all the interactions, such as expand, hover, focus and click.

  • Rename
    This state is used to rename the text label or each node item.

  • Drag & Drop
    This state is enabled during the drag & drop re-arrange mode.

Configurations

RHS Content

The RHS Content is configurable, it can be a Badge, Status Indicator, Colored Badge or a Plain text.

Divider

Each level item has a divider at the bottom and it should be enable only whenever required.

For this instance divider is used to group the parent and its child element when the parent node is expanded.

Behaviours

Expand Behaviour

Clicking on the node expands the node to show the child node/leaf node within it. The entire node is clickable except the action area.

Multi-select Behaviour

Tree view with checkboxes follows the same principle as nested checkboxes.

Usage Guidelines

Don’t interchange the hierarchy icons. The folders are always used on the parent and child nodes, and the stack icon is used for the leaf nodes. Keeping this consistency creates meaningful visual associations.

Don’t remove the leading padding from the second and third level rows. The padding helps create visual hierarchy.
