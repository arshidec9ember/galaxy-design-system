Anatomy

Variations

Avatars are categorized into three types,

  • Picture: A picture of a user or an entity can be uploaded here in a 1:1 aspect ratio for representation.

  • Icon: Illustrated icons representing a user or an entity can be used here.

  • Initials: Initials of the user name/ entity name can be used here for representation. Both a single-letter and a two-letter representation can be used.

Sizes

GDS supports avatars with four different sizes

  • Small - 24px

  • Medium - 32px

  • Large - 40 px

  • X large - 56px

Behavior

Avatars are primarily used to indicate a user or an entity, depending upon the scenario an avatar component can be clickable, on clicking the component it might elaborate details about the represented user or an entity.

Usage Guidelines

Don’t

Do not use an avatar as a substitute for an icon button.

Initial variant of the avatar should not include more than two initials
