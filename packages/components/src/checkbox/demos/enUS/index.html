Anatomy

Variations

The choice group has two categories based on single v/s multiple selections. And each type has both orientations based on the horizontal and vertical presentation of the items.

Multi-select

It contains a group of multi-select items represented by checkboxes. The checkbox could be followed by a label or an image as well.

Single Select

It contains a group of mutually exclusive items represented by radio buttons. The radio buttons could be followed by a label or an image as well.

States

Similar to the form field interactions the choice group also aids users in understanding every state of the component as the user interacts with it. Each state represents an action that is either performed or triggered in the course of an input.

  • Default, Hovered, Focused, and Selected states are the same as described for a standalone checkbox or a radio button.

  • Disabled
    Disabled states blocks all the interactions on the complete choice group such as hover, focus and click.

  • Error
    Upon performing validation on the given input the system throws an error aiding the user with the error information.

Behaviour

Orientation

A Choice group can be both aligned vertically as well as horizontally depending upon the scenario.

Selection

The Multiselect choice group allows for selecting multiple items.
The Single Select choice group allows for selecting only one item. Selecting another item once an item is already selected, selected the new item and deselected the previous item.

Usage guidelines

Do’s

Logos used in the image option should be at the height of 24px (Small)

Dont’s

A choice group should always contain a minimum of 2 options.

Avoid combining horizontal and vertical variants together.

Caution

Consider using the Select component when there are large number of items to select from.
