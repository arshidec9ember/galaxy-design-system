Links allow users to navigate to a different location. They can be used on their own or inline with text.


Anatomy

Link anatomy consists of “Text label” whose purpose is to Communicate what is being linked to and a support icon for showing if link directs to external page or window.


Variations

We are supporting two variations of links now. Normal link and Inline link

Normal Link

These are the default link variation which do not comes with underline and is recommended to use whenever you have a use case for showing standalone links.

Normal links can be paired with trailing icon representing that this link will take you to new page.

Use a 16 px icon with the same color token as of link text.

Inline Link

Inline links are used within a sentence or paragraph and comes with the underline by default. This helps in differentiating the link from the rest of content and makes it clear and easy to interact.

These links should not be paired with an icon. As using icons inside a sentence can add extra cognitive effort for readers and also disrupt the continuity of the reading behaviour.

Bold Links

Bold links are links with high emphasis and are intended to be used when they are used as standalone links. They could also be used in the tables to indicate clickable row texts.

Sizes

There are two size variants for the link component: Small(12px) and Normal(14px)

States

There are six states for links:

  • Enabled

  • Hovered

  • Focussed

  • Pressed

  • Disabled

  • Visited

Behaviours

Label size

The size of the links, which is the font size is dynamic and it matches the size of the text it is used inline with. And the default size is set to 14 px and 12 px for small links.

Interaction

With Mouse : Users can open a link by clicking anywhere along the link text or on the associated icon. With Keyboard : Users can open a link by pressing Enter while the link has focus.

Buttons versus links

Links are used primarily for intra product navigation or to switch to different screen all together. On the other hand, Buttons are used primarily for actions such as “Add”, “Cancel“, “Save“ etc.

Now plain buttons which looks similar to links should be used for less important actions like “View details“, “View all”, “See more”, “Previous“, “Next“ etc.

Visited style

By default links do support having a purple color visited style helping user recognising which of the links on the page are already visited.

But this style also brings extra visual noise on the screen by showing mix of visited & unvisited links. So we recommend to use visited style sparingly and only at those places where it’s actually important to let users know about the visited links.

Usage Guidelines


Do’s

  • Use links for navigation within or directly accompanying a sentence.

  • Use links for Directing users to another page or a different section of the same page.

  • While using standalone links, make sure to provide enough context within the link about where the link will take the user.

Don’ts

  • Do not use links for actions that will change data or manipulate how it is displayed, change a state, or to trigger an action. Use a plain button instead.

  • Do not use custom colors for links.
