Anatomy

Variations

Based on use cases accordion users can choose from two options for an accordion :

Box accordion

The box accordion is a variant that features a complete container visual with an outlined stroke. It is recommended to align the container boundary with the rest of the content when placing it on a page. Additionally, when designing the content inside the accordion, it is advisable to align it with the indicator button.

Inline accordion

This particular variation is intended for use within various content layouts. When designing the content inside the accordion, it is recommended to align it with the leading icon rather than the indicator button for optimal alignment.

Configurations

An accordion can be configured in four ways, depending on the use case:

Simple accordion: An accordion without any action or additional configuration.

Action-only accordion: An accordion with actions only on the right-hand slot.

Content-only accordion: An accordion with only additional content on the right-hand slot.

Action and content accordion: An accordion with both actions and additional content on the right-hand slot.

States

The accordion element has different states that are significant for its overall functionality and user experience:

  • Collapsed state: Accordions begin in a default collapsed state with all content panels closed. This provides users with a high-level overview of the available information without overwhelming them with too much detail.

  • Hovered state: This state defines the visual feedback of an accordion when the user hovers over it, usually with a change in the background container color to indicate interactivity.

  • Focused State: The focused state provides feedback when a user has highlighted an element using a keyboard or voice. This state is typically indicated by a blue, thick outline around the container.

  • Expanded State: An accordion in the expanded state reveals the content inside it progressively. The chevron icon at the start of the accordion indicates whether it is in a collapsed or expanded state. The chevron pointing right indicates a collapsed state, while the chevron pointing down indicates an expanded state.

  • Disabled: This state disables the accordion based on the context and use case, preventing users from interacting with it when necessary.

Behavior

Expand Behaviour

Accordions can exhibit two distinct types of expanded behavior:

Single expand: With this configuration, only one header can be expanded at a time. Clicking on another header will close the previous one, ensuring that only one section is open at any given time.

Multi-expand: With this configuration, multiple headers can be expanded simultaneously, allowing users to view multiple sections of content at once.

Clickable area

The accordion element can be expanded or collapsed, with the current state indicated by a chevron icon in the header. Users can initiate a state change by clicking on the chevron icon or anywhere within the header area, providing intuitive and flexible interaction options. Overall, the accordion offers a user-friendly way to manage and organize content within an interface..

Usage Guidelines

Do’s

Use accordion to progressively disclose the content and organize related information.

To reduce scrolling and shorten pages when content is not crucial to read in full, when space is at a premium.

Don’ts

Accordions should be avoided when your audience needs most or all of the content on the page to answer their questions.
