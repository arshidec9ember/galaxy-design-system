Anatomy

Filter Types

1. Default Filters

Default filters are of two types:

- System Defined Filters

Filters that are pre defined by the product or system itself. GDS allows product teams can establish these pre defined filters for end users. Unlike user applied filters, these are non-removable filters but can be reset to their default value.

- User Applied Filters:

These filters are applied by the end user based on their specific needs or preferences. Users can select from a range of options under Add Filter to refine the data according to their requirements. These are removable filters.

Behaviour

Overflow:

The filter bar can wrap to multiple lines, without any restriction. Users can add and remove as many filters as they want. Add filter button and reset links are always grouped together.

Add/reset Filter:

User can add a filter using the add filter button. It shows all the available attributes in the popover and user can choose to filter by value or condition.

2. Quick Filters

Quick filters allow users to easily and quickly apply predefined filters to a dataset. They are useful for users who want to perform a rapid, focused analysis of data without the need to configure complex filter settings. They are presented as interactive controls that can be toggled on or off with minimal effort.

Quick filters can be used alone or on top of the default filters.

States

Size

Quick filter chips are available in one size i.e. 28 px

Variants

Quick Filter has below variants based on the value of the quick filter chip:

  1. Icon + Text

  2. Text Only

  3. Icon Only

Configurations

There are below two configurations in which a user can utilize quick filters:

  1. Quick Filters alone: In this scenario, the product doesn’t have any default filters and would like to refine the data based on some pre defined quick filters only.

  1. Quick filters with default filter: Here the product can choose to provide default filters along with quick filters. There are two placement options in this configuration:

  • Quick filters on top of default filters

  • Quick filters inline with default filters

Note: This placement should be used only when the product has a finite set of quick filters and default filters.

Interaction Behaviour

There are 2 interaction behaviours:

  1. Default filter chip addition : When a user selects a specific quick filter chip, a default filter chip is automatically added with the same value as the quick filter. This interaction does not maintain a selected state for the quick filter. This interaction is available when quick filter is used along with default filters.

  1. Without adding a default filter chip : When a user selects a particular quick filter chip, the dataset below it is refined based on the selection. The quick filter chips maintain selected states to indicate which one the user has chosen to filter the dataset.

Usage Guidelines

User proper condition tags while using filter by condition.

Do not mix default filter chips and quick filter chips to create one filter bar, they should always be used separately.
