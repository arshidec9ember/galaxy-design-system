Anatomy


Variations

We are supporting two variations of breadcrumbs as of now. Depending on the emphasis that you want to put on the page title you can use one of the variations.

Default

In this variation page title is inline with other breadcrumbs items maintaining the order of hierarchy ( from left to right )

With Enhanced Title

This variation focuses on bringing more emphasis on the page title while maintaining the order of hierarchy.

This style of enhanced title is majorly used in our page banners. Link to page banner

States

Breadcrumbs essentially uses the Links. Therefore the interactive states of a breadcrumb are the same as that of the links, except for the visited state. Because by nature of navigation the visited interaction will be repetitive in nature.

States of Breadcrumb:

  • Normal

  • Hovered

  • Focussed

  • Pressed

  • Disabled

Behaviours

Interactions

All the page links in the breadcrumb component are interactive and links to their respective pages.

With Mouse: Users can navigate to any page in the workflow by clicking on the relevant level link.
With Keyboard: Users can open a link by pressing Enter while the relevant level link is in focus state.

Overflow

Breadcrumbs truncate when there is not enough room to display all the levels in the hierarchy. The truncation of breadcrumb items begins when either there is not enough room to display all items, or if there are 5 or more breadcrumbs to display.

The first and last two page links should be shown, but the remaining breadcrumbs in between are condensed into an overflow menu. By default, the truncation happens after the first level.

Level Name

All the levels in the breadcrumbs are by default set to the corresponding page title, or a step title if the breadcrumb is used as part of flow on the same page. By default, the current page/step title is not listed in the breadcrumb trail. It is instead displayed right below the breadcrumb as an emphasized title.

Text Overflow

Level links should be short and clearly reflect the location or page it is linked to. But in case of longer page title names and availability of limited space, truncate the text with an ellipsis.

By default, truncation occurs at the end of the title. But if the end words are required to give context to the users, the truncation can be done in the middle as well.

Placement

Level links should be short and clearly reflect the location or page it is linked to. But in case of longer page title names and availability of limited space, truncate the text with an ellipsis.

Usage Guidelines


Do’s

  • Use breadcrumbs to communicate hierarchical relationships.


Don’ts

  • Avoid displaying too many levels in breadcrumbs upfront. Be mindful of your user’s cognitive load, displaying too many levels can be overwhelming. Use truncation with an overflow menu instead.

  • Avoid displaying the page headings together in the breadcrumb as well as on the page.

  • Avoid using icons within breadcrumbs. Icons disrupt the rhythm and readability of the breadcrumbs.

  • Breadcrumbs should never wrap onto a second line.

  • Avoid truncating more than one breadcrumb label. Prioritize using truncation with an overflow menu instead.
