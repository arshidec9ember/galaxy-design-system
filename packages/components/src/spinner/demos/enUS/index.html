Types

GDS has three types of progress & loaders. 

Progress Bar : A progress bar shows the completion level of an activity. It is generally used for determinate activities like file uploads.

Spinner : A spinner, as the name suggests, spins until an activity is performed. It is generally used for indeterminate events like waiting for network delays, processing data, etc.

Skeleton Loader : A skeleton loader mimics the skeleton of a page or a section. It is generally used for content loading.


Anatomy

Variations

Progress Bar variations

  • With label & completion percentage : It includes a label to indicate the type of activity and a percentage value that indicates the completion percentage of that activity. It is recommended to use this type of a progress bar to inform the user accurately of the completion level.

  • Without label & completion percentage : It is a simple progress bar without the completion percentage. It could be used for indeterminate activities or where the percentage and label is not an important parameter to display, like the loading of a page.

  • Success variant : This variant is used to show the success state of certain activities like downloading/uploading of content. Along with the success color, it can have a leading success icon for better accessibility.

  • Failed variant : This variant is used to show the failed state of certain activities like downloading/uploading of content. Along with the anger color, it can have a leading error icon for better accessibility.

Determinate / Indeterminate state : Progress bar can be either determinate or indeterminate. By default, progress bars are determinate.

Use a Determinate progress bar when progress can be calculated based on the API response. For eg. downloading/uploading a file of a specific size.

Use an Indeterminate progress bar when the time to completion can’t be calculated. For eg. For showing server connection lost in between and now system is waiting for few seconds to connect to server again.

Spinner variations

  • Default Spinner : Use default spinner for displaying loading state of any section that have white or light background. Spinner have blue fills that keeps on rotating till loading of the section finishes.

  • Inverted Spinner : When spinner to be used on top of color dark backgrounds then use the Inverted spinner variant. The inverted spinner uses the white fill color irrespective of the theme. Make sure background color offers enough contrast for spinner to be visible.

💡 Tip

Use the Inverted spinner with Scrim background ( 40% alpha of #020D4D ) for showing the full page loading, if required.


Skeleton variations

  • Default Skeleton : Use default skeleton for displaying loading placeholders for information, while data is still loading in background. This variant uses animated gradient using grey 05 and grey 20 as base colors.

Animation direction is from left to right, timeframe is around 1.5 seconds and using linear easing for continuous loop animation.

  • Inverted Skeleton : Use inverted skeleton to display the loading placeholders over dark backgrounds. Most common use case in our products is the dark global header and Primary sidebar.

This variant uses the same animated gradient using grey 05 & grey 20 as base colors. The catch is in the alpha (opacity) along with colors. So we are using grey 05 with 10% alpha and Grey 20 with 20% alpha to create the lighter variation of the skeleton gradient.

Sizes


Progress Bar sizes

Progress bar come in 4 sizes Large, medium ,small and Xsmall. These are available to fit various context. For eg. large one can be used to show progress happening at full page, while small can be used in places with tight spacing.


Spinner sizes

Spinner also comes in 4 sizes :

Large ( 96 X 96 px )

Medium ( 72 X 72 px )

Small ( 48 X 48 px )

Xsmall ( 24 X 24 px )

Reasons being the same, small ones can be used in place of an icon or in tight spaces. While large/medium can be used to show full page loading.

Skeleton sizes

Skeleton sizes are dynamic and contextual. As we already mentioned that Skeleton loader is customized for different elements of pages/sections, So sizing also depends on the same.

Behavior

Overflow of Progress Bar label

If your label text is too long for the available horizontal space, it wraps to form another line. Avoid truncating the label or using ellipsis.

Spinner

  • A spinner can be used inside another component such as a button, or it could be used on a page overlay or over a section in a page.

  • The spinner keeps rotating until the activity is not complete, or until timeout occurs.


Skeleton Loader

  • All the bars in a skeleton loader animates in a loop. And it starts at the same time for all the bars.

  • The height and width of the bars are flexible. It is generally set based on the height and width of the underlying components.

Usage Guidelines

Don'ts

  • Do not combine multiple types of progress & loaders simultaneously.

Dos

  • To indicate loading on multiple sections of a page, multiple skeleton loaders could be used.
