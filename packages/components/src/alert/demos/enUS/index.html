Anatomy

Variations

All three Alert are further categorised into semantic variants;

  1. Information: is used to convey information that is neutral in nature and may not require as much attention from the user, represented with the color blue.

  2. Success: is used to convey success or completion messages, represented with the color green.

  3. Warning: is used to displaying warning and caution messages, represented with the color orange.

  4. Danger: is used to alert users to an error or a critical scenario, represented with the color red.

Placement

Based on the different use cases the alerts are positioned in two different places -

Header - This placement shows a full-width alert at the top of the page. It creates the space for alert by pushing down the contents of the page (as opposed to an overlay). It is used when information is more prominent in nature, or when a piece of information needs to be displayed for a longer period of time. For example, “Info on a scheduled service downtime can be displayed until the service is live again.”

Inline - This placement is to show the alert related to a specific container or a section on a page. The alert is generally displayed at the top of a container. The width of the alert is flexible in this placement, it can be set relative to the width of the container such that it expands to occupy the full width of the container, or could also be fixed based on the grid columns. They can be displayed with or without action and dismiss buttons as required.

Configuration

Configurations are used to modify the alert component structure depending upon the use case for which they are used. The below mentioned configurations are available for alerts :

Actions

An alert banner ideally provides a way for a user to address an issue with action. It can have an icon-only close button, a secondary button with a contextual action to take, and a tertiary button for an extra action to take.

Action Placement

There are two possibilities for the action placement. They can either horizontally aligned with the title and description or below the description.

Behavior

  • Dismissal

  • Text Overflow

Dismissal

Alert can be dismissed in two ways,

Auto Dismissal: Auto dismissal happens when the user performs the required task in order to dismiss the alert message from the section.

Voluntary Dismissal: Voluntary dismissal happens when the user clicks on the dismiss action button “x” or any other action buttons in order to close the alerts or acknowledge the notification.

Text overflow

When the Alert description text is too long for the available container width, it wraps to the next line.

Usage guidelines

Do’s

Keep an alert banner’s message concise while still being clear, using either a short phrase or a complete sentence that describes what’s happening and what someone needs to know.

Don’t

Don’t use two actions with the same level of emphasis. Use the button variations to create right emphasis and help users clearly identify the primary action. Ideally one should be the main action and the other one should be supportive.

Avoid showing many alerts at the same time. Sequencing can be used to display multiple alerts one after the other.

Don’t use an alert for floating notifications. Use a toast instead.
