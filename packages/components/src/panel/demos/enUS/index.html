The side panel is a vertical container used to fill forms, display related information or navigation. It enables users to view content while referencing the relevant page information within a defined context. It streamlines data input, keeping important content accessible alongside the form for an enhanced user experience.

Side panel by default compress the parent content to left and opens in the right side of the screen. It can also be configured to open on top of the parent content without any overlay.

Anatomy

The side panel header comprises of:

  1. Title

  2. Tools (It’s a button group and can be configured based on usage and requirement)

  3. Side panel actions (This would be present in case of details view)

The side panel footer has:

  1. LHS actions (These will be present if the side panel is used to submit a form)

  2. RHS navigation (This will be present only in case of parent-child view to traverse the table rows)

The collapse icon will be visible only on hover of the side panel but the expand icon will always be visible on the collapsed state to expand the side panel.

Configuration

The side panel can have either of the below two configurations:

  1. Expand/collapse action: This configuration is used when the side panel is used to submit a form or a task where user action is required.

  1. Close action: This configuration is used when the side panel is used to display details or some related information where no user action required.

Variations

1. Sliding the parent content

One variation would be that the side panel enters from the right side of the screen pushing the contents to the left. This variation is available in case of responsive layout. If the user drags the side panel to expand the view, the parent content continues to shrink until both the containers occupy a 50-50% space on the available view port.

Behaviours

Expand & collapse

The side panel can be collapsed and docked to the right side of the screen. The collapse icon is displayed only while hovering the side panel. To restore the expanded view, the expand icon will always be visible on the collapsed state of the side panel.

Drag to expand view

On hovering the side panel’s left edge, a visual indication is present which includes blue line as well as resize icon. On dragging the side panel, the user can resize it to expand the view.

Expand to full screen

On click of expand icon, the side panel is directly expanded to the full screen view.

Open in new tab

The side panel can also be opened in a new tab where it opens as full page view. But here there won’t be any side panel tools available.

Vertical Scroll

The side panel has a vertical scroll if the content is more than the height of the component. In this case the header will have a shadow to show the content flowing behind it.

Height and width

The side panel covers the whole view port height below the global header. The minimum width is 300px and maximum it goes up to 80% of the view port width.

Usage Guidelines

Header should be sticky in case of vertical scroll.

The collapse icon should be available on hover.
