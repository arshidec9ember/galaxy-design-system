Anatomy

Variations

A file uploader can be classified into two categories based on usage.

Single-file uploader

Default

Default is a field-level component that can be used among a group of form fields, which supports both drag-drop and click to upload documents.

Large

A large file uploader provides a dedicated real estate for the users to drag-drop a document as well as click to upload a document.

States

Interactions aid users in understanding every state of the component when the user interacts with it, each state represents an action that is either performed or triggered in the course of uploading a document.

  • Default: The default state is a state zero of the component before the user interacts or performs any action over it.

  • Hovered: It defines the visual feedback of the fields when hovered over.

  • Focused: Focused is triggered when a field is activated by either clicking or navigating to it using the keyboard or voice.

  • Uploaded: It represents the uploaded state of the component.

  • Disabled: It is an inactive state in which the user can not interact with the component. A state change can be triggered by providing permission to edit or by performing a prerequisite action.

  • Error: It represents the error and highlights the field to aid the user to enter the correct information. It is triggered when the field validation fails.

  • Uploading: It is a loading state in which it showcases a loading spinner or a progress bar to indicate the amount of data that has been uploaded.

Behavior

Data processing

When a document is uploaded the application tends to process the document and upload the data in bytes parallelly verifying if the document uploaded follows respective parameters such as document size, format, etc. To aid the user in understanding how much document is uploaded, a Spinner loader/ Progress bar is used to represent the overall progress and the amount of data uploaded.

Image preview

On the Drag-Drop file uploader variant, when an image is updated the user will be able to use a hover effect to showcase a document name and format.

Larger images can be opened with the help of a model preview, the representation would remain the same the designers could choose either a medium size modal or a larger modal accordingly to showcase the images.

Sub text

Subtext provides users a piece of additional supportive information for the document that needs to be uploaded.
