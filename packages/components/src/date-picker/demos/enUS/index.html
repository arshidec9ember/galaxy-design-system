Anatomy

Variations

Date field

The date field allows users to select a specific date or range of dates from the given list.

Time field

The time field allows users to select a specific time or range of time from the given list.

Date & Time field

The Date and Time field is a combination of two fields that allows users to select a specific date and time from the given list.

States

Form field interactions aid users in understanding every state of the component the user interacts with, each state represents an action that is either performed or triggered in the course of form filling.

  • Default: The default state is a state zero of the component before the user interacts or performs any action over it.

  • Hovered: It defines the visual feedback of the field when hovered over.

  • Focused: Focused is triggered when a field is activated by either clicking or navigating to it using the keyboard or voice.

  • Filled: It represents the filled state of a field with the characters.

  • Disabled: It is an inactive state in which the user cannot interact with the component. A state change can be triggered by providing permission to edit or by performing a prerequisite action.

  • Error: It represents the error and highlights the field to aid the user to enter the correct information. It is triggered when the field validation fails.

Behavior

The feedback is displayed in the required format configured for the fields.
