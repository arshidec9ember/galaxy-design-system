Anatomy

Variations

Cards have two variations based on its structure orientation.

Vertical

In this type of card, the card elements such as Header, Body are stacked vertically.

Horizontal

In this type of card, the card elements such as LHS Header and the Body are stacked horizontally. Whereas the Footer is stacked below the body, and parallel to the LHS header.

Action Types

Floating Action Button

A card can have a floating action button in the top right corner. Such a button displays on hover over the card. It can be used as a menu of actions as well.

Action Footer

A card can be enabled with the footer which contains action group.

Elements

  • Header (for vertical card)

  • LHS Header (for horizontal card)

  • Body

  • Footer

  • Badges

Header

Header acts as a visual identifier to provide extra context. It is an optional element and can be used when required. GDS has the following header variations for vertically structured cards.

LHS Header

Similar to Header in vertical type, LHS Header also acts as a visual identifier to provide extra context in the Horizontal card. It is an optional element and can be used when required. GDS has the following header variations for the Horizontally structured cards.

Body

Body is the core of the cards. It is used to display the information like, Title, Description, Subtext and all the different types of Badges and Status Indicators. Since its a core for the cards, the elements are common for both, the vertical and the horizontal cards.

Body can contain one or more of the following types of information and components. While using multiple information types, they can be ordered in any sequence as required to create a relevant hierarchy.

Footer

Footer is used to provide upfront actions. One or more buttons can be used in the footer, as required. The following example shows different ways in which buttons can be used in a footer.

In the vertical card, the footer is represented with a divider to enable better focus over the body and the actions. Whereas in the horizontal card the footer doesn’t contain a divider and the padding between the body and the footer is reduced to keep better proportions.

Badges

The badges and status indicators can be positioned in the following ways:

  • On the right end of the Header in the Vertical card

  • On the right end of the Title in the Horizontal cards

  • Left aligned in any order in the Body of both the card types

States

The card has four states: Default, Hovered, Focused and Selected.
Clickable card has two interactive feedbacks, the shadow depth and the cursor change, to indicate the user of the click action on the card.

If a card is configured as selectable, then in selection mode a selection signifier appears on the top left corner of the card on hover.

A card group can be configured as single select by replacing the checkboxes with the radiobutton.

In a grid view the selection signifier is displayed by default over all the card if it is in the bulk action mode.

For the Tile cards, the interactive states are little different since it doesn’t have any shadow to denote the place differences. Instead there could be a color differences in all states.

Behaviours

Height

  • The minimum Height of the card is fixed as 80px.

  • Card height is responsive since its depends upon the number of elements placed in a card, header and footer.

  • The height of the footer is fixed. Whereas the header and the body are responsive.

Width

  • Card width occupies the container width, that can be set based on the column width and number of columns used in the layout.

  • The minimum width of the card is fixed as 171px.

Truncation for each Element

Since the height of the card is variable, the number of lines for each element can be fixed as required. For eg. Title and Description can be set to a maximum of two lines, beyond that the text will truncated with ellipses. The hidden texts will be visible on hover in a tooltip.

Interactive Area

A card without an action footer is entirely interactive. And if the card has an action footer, the footer action as well as the entire card is interactive.

Layout

Card Layout Grid

The Cards can be arranged like a grid, and the number of cards per row is depends upon the type of template. By default we have 4 cards in a row. In some rare scenarios the no of cards could go till 7 (in calendar view template), so the Min width would be 171px.

Card Height in Grid Arrangement

Incase the card is arranged in a Grid view, the Card body Height will be derived from the parent (i.e., the container)

Tile Layout Grid

For tile card layout there is no gutter space and no corner radius present for the the card. Instead of gutter space there is divider is placed in between each tile as boundary. And card’s inner margin may vary upon the usecase.

Usage Guidelines

  • Don't use more than one header, title or description elements in the same card.

  • Do follow the truncation guidelines for the each element type.

  • Don’t set the height of the individual cards to its content if the cards are placed in a grid.

  • Avoid using mixed card variations in the grid layout.
