# Card Media

Can behave as a cover around the card, a media on top of the card, as a strip and many more. Use this in combination with [`<z-card-action-area />`](/en-US/light/components/card/action-area) or a parent with relative positioning.

## Examples

```demo
card-cover.vue
media.vue
media-n-action-area.vue
gradient-media.vue
image.vue
video.vue
background.vue
```

## API

### Card Media Props

| Name | Type | Default | Description | Version |
| --- | --- | --- | --- | --- |
| background | `boolean` | `true` | Whether it should wrap the card area background positioned to relative parent |  |
| tag | `string` | `'div'` | What tag need the card be rendered as. | 2.34.3 |

### Card Media Slots

| Name    | Parameters | Description         |
| ------- | ---------- | ------------------- |
| default | `()`       | Card Media content. |
