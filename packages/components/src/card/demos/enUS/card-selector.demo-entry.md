# Card Selector

Wraps the card inside it with radios or checkboxes.

## Demos

```demo
selector.vue
```

## API

### Card Selector Props

| Name | Type | Default | Description | Version |
| --- | --- | --- | --- | --- |
| multiple | `boolean` | `false` | Whether the card selectors are checkboxes | 2.34.3 |

### Card Selector Slots

| Name    | Parameters | Description            |
| ------- | ---------- | ---------------------- |
| default | `()`       | Card Selector content. |
