Anatomy

Variations

GDS Sidebar has 3 variations, where depends upon the context we can position it effectively. For one instances the Dark one is act as a Primary, and followed by the Secondary sidebar. In some instance there will be no Darker sidebar, so we might use Secondary or File Explorer type.

Levels

Nodes

The Nested of each accordion item is decided by the type of Node used. We have two node, one is Parent Node and other one is the Child Node. And the Parent and Child is node is differentiated using the Chevron. If the level doesn’t have any child node, we can disable the chevron so that it will act as a standalone level.

Levels

The main element of sidebar component is the Levels, where it will act as an accordion item and we can expand and collapse the item using the chevron to reveal the inner levels items. The Levels can be configured to have upto 'n’ th levels but as per the GDS guideline maximum number of levels is restricted based on the context, For eg. If the Sidebar is used a primary navigation, it has a restriction of levels upto 3. If the sidebar is used as the File Explorer context, there is no restriction on number of levels.

Accordion State

The state of each parent node is decided by the chevron icon, and it has two state which are Collapsed and Expanded. If it is in expanded state the inner levels of the parent node will be visible.

Configurations

GDS sidebar support various other features like a Switcher at the top, Separator & Subheading to create groups of menu items and Search to search across the menu items, Selector, Icon,

Switcher

Lets start with a switcher, It can be used to change settings on a global level which can in turn change the sidebar options or the content within. If Switcher is used, it has to be the top most option and cannot be used in the middle of the Sidebar. Switch has two options With and Without Interactive State.

Subheading

Subheading is just a text to help group different sections on a Sidebar. There are two types of Sub heading With/Without Search.

Subheading with search which is indicated by a search icon on the right. On clicking the subheading, it turns into a search field, letting users search for a particular sidebar element under the said subheading.

Interaction States

Irrespective of the levels, each node has the interactive states. And there is some visual changes as per the variation, whether it's in Dark or Light.

Icon

Depends upon the context the usage of icon differs. Incase of the primary sidebar the icon should present only on the Level 1. And incase of the Secondary sidebar we should provide an Icon. But in case of the File Explorer, we need to provide icon for all the levels to denote whether the folder is expanded or collapsed in addition to the chevron.

RHS Content (Optional)

Each level has a content on the RHS and the type of content may vary upon the usage, we have Badge which has an alphanumeric value which is used to show any pending items or number of items inside or even we can show ‘‘New’ text in case we want to highlight the level. We can also have any statuses, Or any plain text to denote something.

Action - On Hover (Optional)

While clicking on the horizontal kebab menu which comes on hover, it will open a popover. The popover might have the option to create a new level inside it. And it also includes the rename and delete option.

After clicking on the Add new option, it will open an input field so that we can give a custom name for the particular level which we have added. Each level is accompanied by hover options as well as the newly added level too. So if someone wants to delete the newly added levels he can delete it from the popover triggered by the Horizontal kebab -> Delete. If the page is empty we can proceed without any confirmation, if the page is filled with anything or if it has any child levels we can prompt confirmation so that it won’t delete accidentally.

Selector (Optional)

Incase if we are in the bulk option mode or in edit mode, we can enable the selector in each levels. The selector can be configurable as Single select (Radio Button) or Multiselect (Checkbox). This would mostly useful feature when we consider File Explorer since we can bulk select the files and folders at ease.

Rearrange/Move

When the Drag & Drop rearrange mode is enabled each node will have the drag and drop icon which can be used to rearrange each level item across the nested levels. This one also mostly useful feature when we consider File Explorer since we can move the files and folders at ease.

Rename

We can rename the label of each node by clicking the horizontal kebab menu which comes on hover, it will open a popover. It includes the rename option.

Divider

Each level item has a divider, but it will be only used to create distinction between two sections of Sidebar. A Divider can be followed by a Subheading or Level 1.

Behaviours

Width & Height

A sidebar is the most prominent navigation for most dashboards and is present on every screen other than the landing page (if any). The Primary sidebar obeys GDS grid structure and has the fixed width of 244 px, also it never stretches or shrinks on different view ports. But it has Resize option where we can enlarge the width of the Sidebar manually as per the need. Height of the sidebar is dependent on the viewports, as it will stretch accordingly.

Collapsible (Optional)

Sidebar can be collapsible using an action that will appear on hover.

Expandable (Optional)

And also the sidebar is expandable using the same action, and the action stays always visible whenever it’s in a collapsed state. And the collapsed state also has hover functionality, whenever we hover on the collapsed sidebar the floating sidebar will appear on top of the content.

Resize(Optional)

The width of the sidebar can be changed by the user using the resize option on Hovering the edge of the sidebar. This would mostly useful feature when we consider File Explorer since we need to support n levels.

Text overflow

If the content exceeds the designated space then the content will be truncated, although it is advisable to use terms that will fit and avoid longer terms. Incase if we support resize option, the text will utilise the required width.

Character limit
Level 1 (With right icon/badge): 14-20 characters
Level 1 (standard): 16-24 characters
Level 2 (With right icon/badge): 14-20 characters
Level 2 (standard): 16-24 characters
Level 3 (With right icon/badge): 13-19
Level 3 (standard): 16-23

Usage Guidelines

  • Navigation items should have concise names and fit within the allocated width in one line. Use names that are clear enough for the users to understand.

  • When the names of navigation items are truncated, use a tooltip on hover to display the complete name.

  • Do not combine Icon and Text only styles of navigation for Level 1 items.
