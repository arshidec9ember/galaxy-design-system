Anatomy

Container: Indicator containers contain the indicator elements (Label and icon).

Indicator: Supports or directly communicates the status using colors, symbols, and, shapes.

Text Label: Conveys the status or other attribute of the metadata. Based on context this can be optional.

Variations

Status indicators are classified into five types based on semantic meaning which denotes different levels of severity: Success, Danger, Warning, Info, and Neutral.
Each of the five types has four variations based on visual emphasis or the level of attention required: Prominent, Subtle, Transparent, and Icon Only.

While deciding the level of prominence of an indicator beware of the cognitive load an indicator might cause.

Indicators Customisations

Neutral indicator

The icon of the neutral indicator is customizable based on the use case. The only thing to keep in mind it should not clash with icons that represent success, warning, and danger semantics.

Icon only indicators

The icon-only indicator can be combined with any other component to bring system status to it. Example: A link and an Icon only indicator can be combined to build a clickable indicator.

Behaviours

Status indicators are static (non-interactive) by nature. However, given their dynamic nature they can auto change based on the system status/data.

Text Overflow

Ideally, the status label should be short, concise, and contextual, and long text should be avoided. However, when the label is too long for the available horizontal space, it could truncate or wrap to the next line depending on the use case and context.

If the truncated label in important to easily make sense of the info, then consider wrapping behavior.

Usage Guidelines

  • Use the established semantic color tokens to create a cohesive semantic visual language across the product.

  • Don’t change the semantics of the status indicators. If a use case arises please reach out to the GDS team.

  • Don’t use icons that contain the semantic value of other status indicators in the neutral indicator.
