# Divider

Divider is an utility component which can we used inside any component or used standalone whenever required. Divider indicates the particular section has ended.

## API

### Divider Props

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| dashed | `boolean` | `false` | Whether to show dashed line. |
| title-placement | `'left' \| 'right' \| 'center'` | `'center'` | Title placement. |
| vertical | `boolean` | `false` | Whether to show vertical direction. |

### Divider Slots

| Name    | Parameters | Description           |
| ------- | ---------- | --------------------- |
| default | `()`       | The title of divider. |
