Scrollbar is also an utility component which can we used inside any fixed container and scroll to view the content inside it. Scrollbars indicate a user’s location in a document that is larger than the viewing space. They allow the user to navigate to the rest of the document by moving the window viewing area up or down.

Horizontal & Vertical Divider

This can be used across a page or within components in a page to create a visual separation between content. Example: It is used within a table to create rows. It is also used below tabs to create a base for holding the tabs. Similarly vertical divider can be used to create vertical sections on a page.

Horizontal & Vertical Scrollbar

When the scroll position is horizontal, the user can scroll horizontally if the content overflows the container horizontally. Similarly, when the scroll position is vertical, the user can scroll vertically if the content overflows the container vertically. When the scroll position is Both (default), the user can scroll vertically and horizontally if the content overflows in both directions.
