Variations

Header

We have provided three variations of header component based on the use cases :

  1. With color background : Color background header is generally used in modals and sidesheets to provide a consistency on the type of Shell we are using to show the content.

  1. With plain background and divider : To be used normally whenever there are use cases for plain white headers. Divider is used to create a definitive segregation between headers and body content.

  1. With Grey background : To be used on the wizards and bottomsheet containers.

Footer

Footer also have three variations :

  1. Plain variant : Plain variant with white background.

  2. With Divider : Plain variant with divider on top.

Behaviour

Shadows on containers

Headers and Footers have fixed defined positions relative to the containers. Header will always be sticky to the top and Footer will always sticks to the bottom.

Now normally they don’t use any shadow tokens but in scenarios where the scroll is coming on the container we have to provide shadow tokens for both header and footer.

Button group usage in footer

We are using button groups as a component inside footer to support multiple action use cases.

For upto 3 actions, please use the button types in order of the emphasis level on actions respectively. And for more than 3 actions, we recommend to use kebab menu to support rest of the actions.


Usage Guidelines

Don’ts

  • Avoid using Icons in wrong slots. Right slot is defined for close Icon and left slot can be used for back button as well as leading icon if required.

  • Avoid using primary buttons in header, please use tertiary buttons for white background and static-light buttons for color backgrounds.

  • Do not place CTA types in the wrong order, and do not scatter the actions throughout the footer.

  • Dont’ use button with different sizes in the single footer.
