Anatomy

The wizard consists of three major parts Step Header, Stepper panel, and Step Footer bar.

Stepper Panel

Indicates a step in a sequence, highlights the current step, displays the completed and incomplete steps. It also lets users navigate between different steps.

Step Header

It shows the title of the current step with any description it might need.

Footer Bar

It is displayed at the bottom of the wizard, after all the steps. It acts as a final confirmation for all the steps in a wizard.

Orientation

Stepper panel comes in 2 orientations. Horizontal and Vertical.

Options

States

Step panels' step indicator has multiple states, as both are interactive elements and can be used to navigate through the wizards.

  • Incomplete
    A step indicator by default is in an incomplete state. Upon launching the wizard except for the first step all steps are in an incomplete state.

  • Hover
    This state defines the visual feedback of a wizard when hovered over.

  • Active
    An active step signifies the step a user is currently interacting with. On launching the wizard the first step will always be in an active state.

  • Completed
    When a user completes a step the step transitions to a complete state.

  • Error
    If there is an error triggered at any point in the process, the stepper panel also showcases the error in the stepper panel on that relevant step for the user as an affordance.

  • Disabled
    This state disables the wizard based on context and use-case.

Behaviours

Navigate using stepper panel

Users cannot use the stepper panel to navigate to different steps by default.

They can only be able to jump between different steps if/when the steps are in a completed state. This help users to quickly jump to any of the completed steps if they want to review the information.

Expand/Collapse Stepper Panel

Just like the sidebar, Outline can also be collapsed. This gives the user the ability to hide outline when it is not needed.

Text Overflow:

If the content exceeds the designated space then the content will be truncated, although it is advisable to use terms that will fit and avoid longer terms.

Placement

Wizard can be placed as a full page, inside a modal or side sheet. This is decided based on the context of the product use case.

Usage guidelines

Minimum 3 steps

Wizard should be used when the number of steps in a flow are minimum of 3 steps.

First step: Disable Previous Button

Disable the Previous button for the first step in the wizard as there is no previous step to go towards.
