Tooltip is a message box component that appears over elements such as icons, links, etc. when a user hovers over such an element.

Anatomy

Variations

There are two variations for tooltip:

  1. Tooltip without icon: This is the standard tooltip that displays only text on hover. This type of tooltip is useful when the information to be displayed is simple or the context of the tooltip is clear.

  2. Tooltip with icon: This is a variation of a standard tooltip that includes a small icon alongside the text. The icon is typically used to provide visual cues to the user and can help to quickly convey the purpose or meaning of the tooltip, which can improve the overall user experience.

Placement

A tooltip is positioned in relation to its target. There are twelve placement positions, which are set by the placement property. Values of the placement property are as follows: top, top left, top right, left, left top, left bottom, bottom, bottom left, bottom right, right, right top, right bottom. The default placement value is at the top.

Behaviours

On hover

Tooltips appear on hovering over an element. It appears with a smooth “appear” animation style when hovered over. And disappears with a smooth “disappear” animation when the cursor is moved away from the element. The appear and disappear time can be configured based on the usage. By default it appears and disappears immediately.

On click

Tooltips appear on click of an element. It is used to provide feedback to users when an action has been completed. For example, when a user clicks on a Copy icon, a tooltip can appear with the text "Copied" alongside a checkmark icon on the left. This provides the user with visual feedback that the copy action was successful.

Text overflow

By default, the maximum width of a tooltip is (230 px on desktop). This can be customized to better fit the context. When the content of the tooltip exceeds the maximum allocated width, it wraps onto the next line.

Text alignment

The text alignment in tooltip by default uses left alignment and center alignment accordingly based on the appearance of tooltip. In general the left aligned text is used in top left, top right, left, left top, left bottom, bottom left, bottom right, right, right top, right bottom, meanwhile the center aligned text is used in top, bottom only.
